# Festival des Jeux — Vichy Pro 2026

Frontend PWA statique pour GitHub Pages.
Le backend reste l'API Google Apps Script existante.

Fichiers :
- index.html : interface de l'application
- manifest.json : configuration PWA
- service-worker.js : service worker PWA
- icons/ : icônes d'installation

Important :
- Ne pas mettre de données personnelles dans ce dépôt.
- L'URL Apps Script déjà présente dans index.html sert uniquement d'API.
